# 変更履歴

## 2.0.0-rc.1 配布準備（2026-10-07 UTC、未正式公開）

- V2を配布世代として整理。Labフォント内部0.201、従来TTF内部1.000を区別し、一律の改名・版上げを行わない。
- static / variable / bitmap / source の4つの独立ZIP、各パッケージ内の案内・見本・ライセンス・検証記録・チェックサムを用意する梱包経路を追加。
- 古い合格報告や不完全な成果物をそのまま梱包しないよう、現在の入力と検査結果の対応を検証。RCと正式版の品質ゲートを分離。
- TTF利用にはPython不要であること、OS別導入/削除、旧版とLab・静的と可変の名前、同じLab名を更新する際の重複注意を明記。
- 円形記号7字の浮動小数点由来の再現性問題へ対処。既存の確定座標を保持し、実行時の三角関数差に依存しない形へ固定。Linux上で12,776文字の既存形状ハッシュ一致と差分を模した回帰検査を確認。詳細・再ビルド状況・実macOS検査は[再現性記録](REPRODUCIBILITY.md)を参照。
- `己已巳・未末・土士・高髙・吉𠮷` を8書体、16/18/24/32pxの実SJPBと静的TTFで再測定。704描画・448ペア比較で10件の同形を記録。静的TTFの今回のFreeType描画では対象ペアの完全同形なし。画素差を可読性の合格とせず、[優先字形QA](PRIORITY-GLYPH-QA.md)へ記載。
- 出典/ファイル/成果物別の通知対応表を追加。AGPL/CJKVI/Unicodeの既存条件を変更しない。
- 過去のブランチ名、検査日、旧分割ZIP案内を履歴と明記。現在の案内はこの変更履歴と[配布手順](DISTRIBUTION.md)を参照。

従来の2,584文字・18/24px資産、静的TTF 8書体、可変TTF 2書体、1bitストライク32組の範囲を維持します。拡張漢字の全数校正、ネイティブOS/アプリ導入試験、ブラウザー操作試験は、この文書の追加だけでは完了しません。
