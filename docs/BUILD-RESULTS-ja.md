# Singleline JP Lab 試作版 技術報告

実験版 0.201｜2026年10月6日 UTC

16／32 pxを追加し、8書体・4サイズを再検証しました。指定のJIS文字は収録・符号化済みですが、日本語字形の全数校正と小サイズの可読性改善は未完了です。全書体を対象にした検査を終えた試作版です。

JISの25件の複数コードポイント表現も収録済みです。件数は文字識別子・符号化の集計であり、字形の正しさや読みやすさを保証する数ではありません。

## 生成したフォントと実装

- 静的TTF 8書体：Singleline、PC98 Mincho Inspired、Gothic、Italian Reverse Contrast、Serif、Italic、Subscript、Superscript
- 可変TTF 2書体：Gothic／Serif。wght 200–700、slnt −12–0。実際のアウトライン補間と両軸を組み合わせた端点を検証
- 1-bitビットマップ32組：8書体×16／18／24／32 px。16／32は文字サイズで、データは1-bitのままです。各組にPNG、JSONメトリクス、SJPBバイナリを同梱。中心線SVGも付属
新しいTTFは中心線を面に展開して作成しています。Italianは直立した横画の太い逆コントラスト体で、Italicとは別設計です。PC98風明朝は独自の幾何学的解釈で、ROM字形の複製ではありません。

補助面文字、互換漢字、標準化された異体字シーケンス、上付き・下付き機能を扱います。数式組版全般や全Unicode数式記号への対応は範囲外です。

## 今回の修正と既存資産の保全

Subscriptの罫線23字で下端が欠ける不具合を修正しました。字ごとの描画範囲とbearing_y、共通ベースラインで位置を保持し、SJPB v1の形式を維持しています。16 pxの縮小書体で空白になった中点・上点（·／˙）も座標を修正し、TTFを含む全成果物を再生成しました。

固定した既存50ファイルは全てバイト単位で一致しました。JIS漢字の内訳は既存字形2,141字、部品ベースの設計案320字、合成設計案7,589字です。追加2字は別集計です。拡張字形は完成書体として認定していません。

## 検証結果と残る品質課題

全成果物の構造テストは123件成功、失敗・スキップ・欠落成果物は0件でした。全32組の計411,232収録項目で、必要な描画の存在、PNG・元字形との一致、描画枠の欠けを検証。静的TTFの全グリフと可変TTFの4隅の全グリフも機械検査済みです。

実バイナリの全32組で各174字、計5,568通りを目視検査しました。静的TTF 8書体と可変TTF 2書体の4隅の軸端点も確認済みです。既往の190字検査とは対象が重複します。全収録字の手作業による校正は未完了です。

- 残る要確認フラグ：非日本語系IDS候補78字、重ね合わせ239字、囲み構造1,177字、深い合成434字。各群は重複し、確定した誤字の件数ではありません
- 全32組に既存由来の同形3組（剝／剥・塡／填・頬／頰）が残ります。32 pxでは通常6書体に追加のラスタ同形はなく、Subscript／Superscriptに煮／煮の1組が追加。16 pxの縮小2書体は各60組が追加です
- 密な漢字・囲み数字・絵文字の細部は小サイズでつぶれ、32 pxでも一部に混雑が残ります。己／已／巳も書体・サイズによって同形になります。縮小書体の小サイズ利用は特に注意が必要です
OSへのインストール試験は未実施です。HTML見本は生成済みですが、ownVMのブラウザー起動制限により検索・可変軸UIの操作確認はできていません。
